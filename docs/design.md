# openRocode：给多模态大模型用的统一机器人外壳

## 是什么

openRocode 是一个开源的 agent 外壳（harness），让多模态大模型像操作电脑一样操控机器人：看相机画面，在画面上指点、按看到的方向移动，或者写一段程序让机器人执行，再看结果决定下一步。

对模型来说，它就是“3D computer use”：模型只和像素、厘米、画面里看得见的方向打交道，深度、标定、坐标系这些几何换算全部由外壳完成。

## 设计原则

1. **核心极简**（参考 [pi](https://github.com/badlogic/pi-mono)）：核心只有循环、事件、钩子和控制通道，大约七百行。工具、安全、录制、界面都做成扩展。
2. **模型不做坐标运算**：工具收发像素和画面相对方向；返回结果里没有世界坐标，有测试守护这一点。
3. **多种 policy，由模型挑选**：
   - 直接调用工具：每一步都看图，适合定位、对准、出错后的判断。
   - 写程序（Code as Policy）：循环、重试、依据传感器读数做判断，适合结构化、重复的部分。
   - 训练好的策略（VLA 等）：以后作为工具接入，处理灵巧、接触密集的操作。
4. **安全不依赖模型自觉**：身体层对每个动作都有工作空间和力限制；外壳层有钩子可以拒绝或终止；操作员随时可以插话、暂停、急停。物理动作永不自动重试。
5. **接什么都只换一层**：换模型只换适配器，换机器人只写一个身体适配器，核心不动。
6. **全程可回放**：每个回合录下事件流和模型看到的每一张图。

## 和 uni-robot-agent 的区别

[uni-robot-agent](https://github.com/Open-RUA/uni-robot-agent) 也自称“统一的 robot-use agent 外壳”。我们的取舍不同：

| | uni-robot-agent | openRocode |
|---|---|---|
| 核心 | 研究型框架，约 3 MB Python，五层服务加 HTTP | pi 式极简核心，进程内调用 |
| 模型的动作接口 | 世界坐标位姿（米、弧度），多视角手工三角化 | 在画面上指点，按画面方向移动，不碰坐标 |
| 写代码 | 借用 Codex / Claude Code 的命令行工具 | 内建 `run_code` 工具，程序里的每个调用都走同一套校验、钩子和急停 |
| 安全 | 工作空间裁剪、关节跳变拒绝 | 身体层力保护加外壳钩子加操作员控制通道；真机上计划加独立的高频安全回路 |
| 运行环境 | Linux 加 NVIDIA GPU | 一台笔记本加 MuJoCo 即可起步 |

## 当前范围（v0）

- 身体：MuJoCo 桌面场景（浮动平行夹爪、两个相机、杯子、方块、杯垫）。没有手臂运动学，可达性和关节限制暂不建模。
- 模型：Claude（Anthropic API），以及任何 OpenAI 兼容的接口（OpenAI、Qwen、DeepSeek、本地 vLLM）。
- 入口：命令行（`rocode run / demo / replay / tasks / view`），运行中可以在终端或看板里插话、暂停、急停。
- 看板：首页列出所有回合；单个回合有“调试”和“观看”两种布局，支持深色和浅色主题；用 `--view` 启动的回合可以在看板里实时控制。

## 路线

1. 用真实模型跑通四个任务，根据失败改工具描述和提示词。
2. 第二种身体：LIBERO（同样基于 MuJoCo），证明“统一”。
3. Python SDK、MCP 服务（让 Claude Code、pi 等现成 agent 直接驱动机器人）。
4. 带手臂运动学的仿真机械臂，以及第一个真机适配器。
5. 训练好的策略作为工具接入。
